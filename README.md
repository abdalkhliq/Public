# سجل الطلاب

برنامج لإدارة سجل الطلاب: الصف والشعبة والشهر، الغياب، المتابعة والدرجات، والملاحظات، مع نسخ احتياطي واستعادة بملف JSON.

## النشر على GitHub Pages
Settings ← Pages ← Source: Deploy from a branch ← main ← /(root).

## بناء ملف APK
Actions ← Build APK ← Run workflow، ثم نزّل الملف من Artifacts.
